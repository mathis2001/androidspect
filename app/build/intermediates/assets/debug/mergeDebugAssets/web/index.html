About this test

                            
This PoC demonstrates TapJacking: a visually deceptive overlay drawn over an exported activity tricks users into tapping UI they cannot correctly identify — confirming dialogs, granting permissions, or triggering sensitive actions.

                            
Android 12+ note: the system forces overlays to be non-touchable when they obscure other windows (so the overlay cannot intercept touches). The overlay here uses FLAG_NOT_TOUCHABLE by design — touches pass through to the victim activity. The attack is visual deception, not touch interception, and remains effective on all Android versions.

                            
An activity is vulnerable if it does not reject touch events delivered while obscured. Set the overlay to near-zero opacity for a stealth PoC, or use a bright color to demonstrate visually in a report.

                            
Remediation

                            
On sensitive views, add android:filterTouchesWhenObscured="true" in XML or call view.setFilterTouchesWhenObscured(true) in code. This causes Android to drop touch events flagged with FLAG_WINDOW_IS_OBSCURED, making the attack ineffective regardless of the overlay.
